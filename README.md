# 🌐 Personal Portfolio Website

## 📖 Project Overview

This is a single-page responsive portfolio website created as part of a lab assignment by **Student Kevin**. The website showcases personal information, my coding journey, skills, projects, and contact details, complete with a CSS-only Dark/Light Mode toggle. It is built using pure **HTML5** and **CSS3** (zero JavaScript).

- URL Link to website portfolio: [Click Here](https://kevintechnow.github.io/Lab-Assignment-Responsive-Portfolio-Web/)
- URL Link to website design: [Click Here](https://www.figma.com/design/0IN1KtECdkULgCpGGiqutP/Untitled?node-id=0-1&t=7ZJuvYiWEPNwOsOL-1)

## 🎯 Purpose

The goal of this project is to:

- Practice responsive web design techniques
- Learn how to structure and style a webpage using modern CSS
- Showcase personal and beginner Computer Science projects in a professional format

## 👥 Target Audience

This portfolio is designed for:

- [✅] Potential employers, instructors, or recruiters

## 🧱 Technologies Used

- **HTML5** (Semantic elements, forms, SVG icons)
- **CSS3** (CSS Variables, `:has()` Dark Mode selector, Flexbox, Box Models, Glassmorphism, Keyframe Animations, Media Queries)
- **Tools** (VS Code, Git & GitHub)

## 📐 Layout & Sections

The website includes the following sections:

- **Header** – Navigation bar with glassmorphism effect (`MyPortfolio.`) and a pure-CSS Dark/Light mode toggle button
- **Hero** – Introduction (`Hi, I'm Student Kevin`), tagline, profile photo (`images/profile.jpg`), action buttons, and animated scroll indicator
- **About Me** – Short bio as a Computer Science beginner and a **My Journey** card detailing my learning goals
- **Skills** – Grid displaying technical skills and tools (`HTML5`, `CSS3`, `PYTHON`, `C++`, `VS Code`, `Git & GitHub`)
- **Projects** – Cards showcasing sample builds (`CSS`, `HTML`, and `Portfolio`) with descriptions and links
- **Contact** – Social media links (YouTube, WhatsApp, GitHub, Instagram, Twitter/X, Facebook) and a contact message form

## 📱 Responsiveness

The site is optimized for:

- Desktop (`@media (min-width: 768px)`)
- Tablet
- Mobile
